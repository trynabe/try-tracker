# Try-Tracker

แอปจัดระเบียบชีวิตประจำวัน รวมการติดตามนิสัย งาน และเวลาโฟกัสไว้ในที่เดียว รองรับภาษาไทย–อังกฤษ ใช้ได้ทั้งคอมพิวเตอร์และมือถือ

## ฟีเจอร์หลัก

- **ภาพรวมวันนี้** — ดูนิสัย งาน และตารางที่ต้องทำ
- **ติดตามนิสัย** — ตั้งเป้าหมาย เช็กความคืบหน้า และดูจำนวนวันที่ทำต่อเนื่อง
- **จัดการงาน** — กำหนดวันส่ง ลำดับความสำคัญ และงานย่อย
- **จับเวลาโฟกัส** — ใช้นาฬิกาจับเวลาหรือ Pomodoro พร้อมบันทึกประวัติ
- **ตารางและปฏิทิน** — วางแผนรายวัน/สัปดาห์ และนำเข้ากิจกรรมจากไฟล์ `.ics`
- **โน้ตและสถิติ** — จดบันทึก ค้นหา และดูสรุปความก้าวหน้า
- **จัดการข้อมูล** — สำรอง/นำเข้า JSON กู้คืนจากถังขยะ และซิงก์ผ่าน Supabase

## เทคโนโลยีที่ใช้

| ส่วน | เทคโนโลยี |
| --- | --- |
| หน้าเว็บ | React 19, JavaScript, CSS |
| เครื่องมือพัฒนา | Vite 7 |
| บัญชีและฐานข้อมูล | Supabase Auth, PostgreSQL |
| ปฏิทินและไอคอน | ical.js, Lucide React |

## โครงสร้างโปรเจกต์

```text
try-tracker/
├── src/             โค้ดแอป หน้าจอ และสไตล์
├── public/          รูปภาพและไอคอน
├── supabase/        โครงสร้างฐานข้อมูลและ migrations
├── tests/           ชุดทดสอบ
├── docs/            คู่มือพัฒนา
├── .env.example     ตัวอย่างการตั้งค่า Supabase
└── VERIFICATION.md  บันทึกผลการทดสอบ
```
