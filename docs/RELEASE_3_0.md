# Try-Tracker 3.0.0

5 พฤศจิกายน 2569 / 5 November 2026

## การเปลี่ยนแปลง

- เพิ่มสวิตช์ **Glassmorphism UI** ใน Settings พร้อมแถบปรับความใส **0–200%** พื้นผิวกระจกครอบคลุมการ์ด เมนู ฟอร์ม และสถานะที่เลือก ธีมมืดใช้พื้นดำผสมสี accent ที่เลือกไว้
- จัดหน้าตั้งค่าเป็นหมวดบัญชี ความปลอดภัย รูปลักษณ์ ภาษา การแจ้งเตือน การสำรองข้อมูล และถังขยะ ปรับระยะข้อความและขนาดปุ่มสำหรับคอมพิวเตอร์กับมือถือ
- จัดตัวกรองงานเป็นสองกลุ่มในกรอบกระจก เพิ่มไอคอนและจำนวนงานให้สถานะ ฝั่งความสำคัญสูง/เกินกำหนดจัดชิดขวาตรงแนวช่องค้นหาบนคอมพิวเตอร์ และแยกเป็นแถวพอดีจอบนมือถือ
- หน้าต่างเพิ่ม/แก้ไขข้อมูล เลือกสี และเลือกไอคอนซูมพร้อมเฟดเมื่อเปิด ฉากหลังเบลอ ปุ่มปิด, Escape และการคลิกฉากหลังของหน้าต่างส่วนกลางใช้แอนิเมชันปิด
- หน้าต่างส่วนกลางแสดงผ่าน portal เพื่อให้ครอบคลุมทั้งหน้าจอ แม้เปิดจากการ์ดที่ใช้เอฟเฟกต์กระจก และยังคืนโฟกัสกับการเลื่อนหน้าเมื่อปิด
- เอา tooltip ที่เด้งเมื่อชี้เมาส์ออก ปุ่มยังมีชื่อสำหรับโปรแกรมอ่านหน้าจอ ปุ่ม Dock บนคอมพิวเตอร์เด้งเบา ๆ ทั้งปุ่มหนึ่งจังหวะเมื่อชี้เมาส์ และป้ายจำนวนงานใช้กรอบกระจกฝ้า
- หน้าแรกใช้การจัดแถวการ์ดนิสัยแบบเดียวกับหน้านิสัย: จอกว้างเรียงได้สามคอลัมน์ และปรับลดคอลัมน์ตามพื้นที่
- เอากรอบใหญ่รอบวันในแถบเลือกวันที่ออก เหลือกรอบกับไฮไลต์รอบเลขวันที่ รวมถึงโฟกัสจากคีย์บอร์ด

## ความเข้ากันได้

- ป้ายเวอร์ชันและชื่อแท็บเว็บแสดง **3.0**; package และ lockfile เป็น **3.0.0**
- `/`, `/preview/2.6` และ `/classic` ใช้เส้นทางและข้อมูลเดิม ตัวระบุ presentation ภายในยังเป็น `v26`
- การตั้งค่ากระจกบันทึกกับโปรไฟล์และไฟล์สำรอง JSON โปรไฟล์เก่าที่ไม่มีค่าดังกล่าวยังปิดโหมดกระจก และใช้ความใสเริ่มต้น 55% เมื่อเปิดโหมดนี้
- ระดับความใสเกิน 100% ลดแสงสะท้อนและความฝ้าต่อ โดยไม่สร้างค่า opacity ติดลบ
- รองรับการลดแอนิเมชันและการลดความโปร่งใสตามการตั้งค่าระบบ
- รูปแบบข้อมูลสำรองเดิมยังใช้ได้ ไม่มีการเปลี่ยน schema ของฐานข้อมูลในรุ่นนี้

## การตรวจสอบ

ใช้ `npm test`, `npm run build`, `git diff --check` และตรวจหน้าเว็บจริงบนคอมพิวเตอร์กับจอมือถือจำลอง ดูผลล่าสุดใน [VERIFICATION.md](../VERIFICATION.md)

การตรวจ UI ไม่ได้ทดแทนการทดสอบระบบบัญชี การแยกข้อมูลผู้ใช้ และการซิงก์ข้ามอุปกรณ์แบบครบขั้นตอน รายละเอียดขอบเขตเดิมอยู่ใน [คู่มือพัฒนา](DEVELOPMENT.md)
